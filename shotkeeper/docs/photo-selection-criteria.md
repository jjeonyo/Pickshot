# 사진 선택 기준

ShotKeeper에서 분석 대상으로 선택되는 사진 기준은 다음과 같다.

## 선택 방식

- 사용자는 개별 사진 파일이 아니라 **사진이 들어 있는 폴더**를 선택한다.
- 선택한 폴더 아래의 이미지 파일을 재귀적으로 스캔한다.
- macOS에서는 `Apple 사진첩 열기`로 썸네일 그리드 보관함 목록을 보고, 앨범 필터/검색으로 범위를 좁힌 뒤 사용자가 선택한 사진만 분석 대상으로 삼는다.
- `ShotKeeper_Result` 폴더 안의 파일은 다시 선택하지 않는다.

## 지원 포맷

다음 확장자의 파일만 사진으로 선택한다.

```text
.jpg
.jpeg
.png
.bmp
.tif
.tiff
.webp
```

확장자는 대소문자를 구분하지 않는다.

## Apple 사진첩 직접 연동

- ShotKeeper는 PhotoKit으로 Apple 사진 보관함 목록과 앨범 목록, 표시용 썸네일을 읽되, 목록을 보여주는 단계에서는 유사도/품질 분석을 실행하지 않는다.
- 사용자가 선택한 사진만 `~/Pictures/ShotKeeper_Apple_Photos_Cache/` 아래 분석용 `.jpg` 캐시로 저장한 뒤 분석한다. 원본이 HEIC/PNG여도 분석 캐시는 지원 확장자인 `.jpg`를 사용한다.
- 보관함 탐색 목록은 썸네일 그리드에서 페이지 단위로 더 불러올 수 있으며, 이 제한은 UI 표시 단위이지 분석 대상 제한이 아니다.
- 원본 Photos 라이브러리를 직접 수정하거나 삭제하지 않는다.
- macOS 사진 접근 권한이 없거나 PhotoKit 의존성이 설치되지 않았거나 선택한 사진을 찾지 못하면 사용자에게 오류를 표시한다.

## 읽을 수 없는 파일 처리

지원 확장자에 해당하더라도 파일이 손상되었거나 이미지 디코딩에 실패하면 해당 파일만 건너뛰고, 나머지 사진 분석은 계속한다. UI 상태 메시지에는 건너뛴 파일 수를 표시한다.

## 유지 규칙

사진 선택 방식이나 지원 포맷을 바꾸면 이 문서도 반드시 함께 수정한다.
