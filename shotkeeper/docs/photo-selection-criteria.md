# 사진 선택 기준

ShotKeeper에서 분석 대상으로 선택되는 사진 기준은 다음과 같다.

## 선택 방식

- 사용자는 개별 사진 파일이 아니라 **사진이 들어 있는 폴더**를 선택한다.
- 선택한 폴더 아래의 이미지 파일을 재귀적으로 스캔한다.
- `ShotKeeper_Result` 폴더 안의 파일은 다시 선택하지 않는다.

## 지원 포맷

다음 확장자의 파일만 사진으로 선택한다.

```text
.jpg
.jpeg
.png
.bmp
.tif
.tiff
.webp
```

확장자는 대소문자를 구분하지 않는다.

## 읽을 수 없는 파일 처리

지원 확장자에 해당하더라도 파일이 손상되었거나 이미지 디코딩에 실패하면 해당 파일만 건너뛰고, 나머지 사진 분석은 계속한다. UI 상태 메시지에는 건너뛴 파일 수를 표시한다.

## 유지 규칙

사진 선택 방식이나 지원 포맷을 바꾸면 이 문서도 반드시 함께 수정한다.
