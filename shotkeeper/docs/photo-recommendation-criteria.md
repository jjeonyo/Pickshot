# 사진 추천 기준

ShotKeeper의 현재 베스트샷 추천 기준은 다음과 같다.

## 품질 지표

각 사진은 0~10점 기준으로 다음 지표를 계산한다.

- 종합: 아래 지표를 가중 합산한 최종 점수
- 선명도: 전체 이미지의 Laplacian variance 기반 점수
- 초점: 중앙 영역의 Laplacian variance 기반 점수
- 노출: 평균 밝기가 중간 밝기에 가까울수록 높은 점수
- 얼굴: OpenCV 얼굴 감지 결과의 크기와 중앙 배치 기준 점수
- 표정: OpenCV smile cascade로 감지한 미소 여부 기준 점수
- 눈뜸: OpenCV eye cascade로 감지한 눈 개수 기준 점수
- 구도: 얼굴 위치가 중앙/삼분할 지점에 가까운지, 얼굴이 없으면 edge가 삼분할선 주변에 분포하는지 기준 점수
- 색감: HSV 채도와 밝기 대비 기준 점수

## 베스트샷 선택

같은 그룹 안에서 `종합` 점수가 가장 높은 사진을 베스트샷으로 선택한다.

현재 가중치:

```text
종합 = 선명도 22% + 초점 18% + 노출 12% + 얼굴 12% + 표정 10% + 눈뜸 10% + 구도 8% + 색감 8%
```

## 한계

표정, 얼굴, 눈뜸 점수는 딥러닝 모델이 아니라 OpenCV cascade 기반 휴리스틱이다. 감지되지 않는 사진은 인물 사진이 아닐 수 있으므로 얼굴/표정/눈뜸에 중립 점수 5점을 부여한다.
